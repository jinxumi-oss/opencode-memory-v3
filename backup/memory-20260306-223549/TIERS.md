# 分层聚合管理 (Tier Manager)

> 权重机制已废弃，所有记忆平等对待

---

## 记忆状态

所有记忆块无权重区分，检索时按以下优先级：

1. **时序优先** - 最近访问的记忆优先
2. **语义匹配** - 相关性高的记忆优先
3. **来源分类** - decision/pattern/preference/external

---

## 状态标记

| 状态 | 说明 |
|------|------|
| **active** | 正常记忆，参与检索 |
| **archived** | 归档记忆，仅主动查询 |
| **isolated** | 隔离记忆，手动恢复 |

---

## 生命周期规则（简化版）

| 操作 | 条件 | 执行 |
|------|------|------|
| 归档 | 180日无调用 | 标记为 archived |
| 隔离 | 365日无调用 | 标记为 isolated |
| 唤醒 | 主动访问归档/隔离记忆 | 标记为 active |

---

- 已删除自动升级/降级机制
