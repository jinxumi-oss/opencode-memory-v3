# 工具备忘

## Git命令

```bash
git status          # 查看状态
git diff            # 查看修改
git add .           # 添加修改
git commit -m "..." # 提交
git push            # 推送
```

## 文件操作

```bash
cat file           # 查看文件
grep "pattern" file # 搜索内容
ls -la             # 列出文件
mkdir dir          # 创建目录
rm file            # 删除文件
```

## 工具快捷方式

```bash
~/.opencode/bin/opencode    # 主命令
~/.opencode/bin/memory.sh   # 记忆管理
~/.opencode/bin/distill.sh  # 智能提炼
~/.opencode/bin/indexer.sh  # 索引管理
```

## 环境变量

```bash
source ~/.bashrc         # 加载环境变量
export OPENAI_API_KEY    # 设置API密钥
```
